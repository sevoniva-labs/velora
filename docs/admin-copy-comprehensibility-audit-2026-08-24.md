日期：2026-08-24

## 结论

本轮已完成平台管理全部 15 个入口及应用详情 7 个页签的文案走查。页面功能、ProComponents 组件结构、顶栏、分组菜单、颜色和权限控制保持不变；整改范围仅包括信息层级、业务命名、状态、按钮、表头、表单和反馈提示。

## 主要整改

- 删除没有明确对象、动作和结果的“下一项”列。
- 应用详情统一为：概览、基本信息、登录设置、谁可以使用、账号下发、上线检查、操作记录。
- “接入方式 / 接入状态 / 运行状态”改为“登录方式 / 配置进度 / 使用状态”。
- “访问对象 / 授权方式 / 有效权限”改为“适用对象 / 设置方式 / 当前可使用人员”。
- 应用使用范围明确支持全体成员、部门、用户组、平台角色和指定人员，并保留排除人员、应用角色、有效期、审批和变更预览。
- “访问复核”改为“权限检查”，“复核负责人 / 复核结果”改为“检查负责人 / 处理结果”。
- “服务账号”改为“系统对接”，权限编码不再直接展示，统一转换为“对象 · 操作”的中文名称。
- “在线会话 / 强制下线”改为“登录会话 / 退出登录”。
- “操作审计”改为“操作记录”，“配置发布”改为“配置变更”。
- 配置流程统一使用“待审批 / 待生效 / 已生效 / 恢复上一版本”。
- 登录安全设置不再要求管理员填写秒数，统一使用分钟；“失败锁定阈值”等术语改为直接说明。
- 系统管理员权限展示修正为“全部 / 全平台”，不再显示误导性的“0 项 / 自定义范围”。
- 应用发布状态统一为“待上线 / 已上线”。
