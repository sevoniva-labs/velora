# Velora 文档

本文档目录只保留当前有效内容。历史方案、开发提示词、阶段报告和已经失效的设计均已删除，避免接入方在多份文件之间判断哪个版本有效。

| 文档 | 读者 | 用途 |
|---|---|---|
| [应用接入手册](./application-integration-guide.md) | 应用负责人、开发、运维、平台管理员 | 唯一权威接入流程、接口契约、双方交付物、验收和排障 |
| [架构与产品边界](./architecture.md) | 产品、架构、安全、开发 | Velora、Casdoor 与业务应用的职责边界 |
| [生产运维](./operations.md) | 运维、发布负责人 | 部署、备份、恢复、监控、发布与回滚入口 |
| [安全与合规边界](./security-and-compliance.md) | 安全、审计、合规 | 已实现控制、外部依赖和禁止宣称事项 |
| [微信扫码登录接入与运维](./wechat-login.md) | 身份平台管理员、运维、安全 | 微信开放平台申请、配置、用户旅程、验收与回滚 |
| [生产就绪状态](./production-readiness.md) | 项目负责人、上线审批人 | 当前版本、验收证据、剩余外部事项与 Go/No-Go |
| [品牌规范](./brand.md) | 产品、前端 | 名称、标识和界面品牌约束 |

接口源文件：[`server/api/gen/openapi/openapi.yaml`](../server/api/gen/openapi/openapi.yaml)。Go 接入 SDK：[`server/sdk/velora`](../server/sdk/velora)。

文档维护规则：

1. 接入规则只能修改《应用接入手册》，不得新建第二份接入规范。
2. 当前状态只能修改《生产就绪状态》，不得用日期命名新增阶段报告。
3. 技术实现细节放在 `server/docs/` 对应主题，不在根目录复制。
4. 提示词、临时计划、截图和单次验收记录不进入权威文档目录。
